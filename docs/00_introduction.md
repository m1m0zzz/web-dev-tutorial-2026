# イントロダクション

このチュートリアルでは、フロントエンドに始まり、バックエンド、そしてフロントエンドからバックエンド API を呼ぶところまで、Web アプリ開発を体系的に学びます。ハンズオン形式で、実際に手を動かしながら進めます。

**最終的に、認証付きの公開メモアプリを Cloudflare にデプロイします。**

## この記事について

### 作るもの

「メモアプリ」と呼んでいますが、認証と公開範囲の制御が入るため、Web アプリの基本的な要素はひととおり含まれます。

- メールアドレスとパスワードでのサインアップとログイン
- メモの作成・編集・削除（自分のメモだけ）
- メモごとの公開 / 非公開の切り替え
- 公開されたメモの一覧ページ（ログインしていなくても読める）
- ユーザーごとの公開メモのページ
- 単体テストと E2E テスト
- `git push` すると自動でテストが走り、デプロイされる状態

### 何ができるようになるか

**このチュートリアルの目的は、写経を終えることではありません。** `npm run dev` が動かないときに、何を見ればいいかが分かるようになることです。そのため、各節には「つまずきポイント」を置き、うまくいく手順だけでなく、**失敗したときに何が起きているのか**を書いています。

読み終えると、次のことができるようになります。

- エラーメッセージを最後まで読み、フロント・API・データベースのどこで失敗したのかを切り分ける
- 「動くコード」と「安全なコード」を区別する。特に**他人のデータが見えてはいけない**という要件を、テストで担保する
- 一次情報（公式ドキュメント）を読んで、記事に書かれていないことを自分で調べる

### 想定読者

**必要なもの**

- 何らかのプログラミング言語で、プログラムを書いたことがある
- HTML と CSS を見て、だいたい何が書いてあるか分かる
- ターミナルでコマンドを打てる（`cd` や `ls` が分かれば十分です。[1.6](01_setup.md#16-ターミナル操作に慣れる) で補います）
- Git で commit と push ができる

**不要なもの**（この記事の中で説明します）

- React などのフレームワークの経験
- Node.js / npm のエコシステムの知識
- SQL とデータベース設計
- 認証・認可の実装経験
- テストや CI/CD の経験

TypeScript は、型注釈が読める程度で構いません。[2.3](02_frontend.md#23-typescript-と-jsx-の読み方) で必要な範囲を扱います。

### 前提環境

Windows + WSL2 (Ubuntu) を前提としています。macOS / Linux を使っている場合は [1.1](01_setup.md#11-wsl2-ubuntu) を読み飛ばし、[1.3](01_setup.md#13-nvm) から始めてください。

### 費用

**この記事の範囲は、すべて無料でできます。** Cloudflare のアカウントは作りますが（[3.1](03_backend.md#31-cloudflare-アカウント作成--wrangler-login)）、使うのは無料プランの範囲です。執筆時点の無料プランには、Workers へのリクエストが1日 100,000 件、D1 の読み取りが1日 500 万行・書き込みが1日 100,000 行・容量 5 GB まで含まれ、静的ファイルの配信は無制限です。学習用のアプリでこれを超えることはありません。GitHub も Public リポジトリなら Actions の実行を含めて無料です。

参考: https://developers.cloudflare.com/workers/platform/pricing/

### 進め方

記事本文には、初出の概念は全文を、そこからの変更は差分を載せています。完成コードはリポジトリを参照してください。

https://github.com/m1m0zzz/web-dev-tutorial-2026

各章には、その章を終えた時点のコードのブランチ（`chapter-01` 〜 `chapter-08`）が対応しています。**途中から始めたい場合や、詰まったときに正解を確認したい場合**は、対応するブランチを参照してください。章とブランチの対応は [README](../README.md) の表にあります。`main` は全章を終えた状態です。

```bash
git clone https://github.com/m1m0zzz/web-dev-tutorial-2026.git
cd web-dev-tutorial-2026
git checkout chapter-03   # 3章を終えた時点の状態
npm install
```

> [!NOTE]
> **章ブランチには記事（`docs/`）が入っていません。** 記事は `main` にしかないので、checkout した状態で読むときは GitHub 上で読むか、`git show main:docs/03_backend.md` のようにして取り出してください。

見出しに「任意)」と付いた節は、**読み飛ばして構いません。** 本筋に必要ではないが知っておくと役に立つこと（開発ツール、React の内部の仕組み、レンダリング方式の比較など）をまとめてあります。[9章](09_devtools.md)は章ごと任意です。

### 詰まったときは

順番に試してください。**「動かないから書き直す」は最後の手段です。** 原因が分からないまま直しても、次に同じ症状が出たときに何も残りません。

1. **エラーメッセージを最後まで読む。** 長くても、原因はたいてい最初か最後の数行にあります
2. **その節の「つまずきポイント」を見る。** 既知の罠はほぼそこに書いてあります
3. **節に書かれている確認方法**（「〜と表示されれば成功です」）と実際の出力を突き合わせ、どこまで進んでいるのかを確定させる
4. **章ブランチとの差分を取る。** `git diff chapter-04 -- apps/api/src` のようにすると、完成形との違いが分かります
5. それでも分からなければ切り分ける（どのプロセスが落ちているか、どのリクエストが失敗しているか、環境変数は渡っているか）

[1.9](01_setup.md#19-任意-claude-code--codex) で入れる AI エージェントに、エラーメッセージごと相談するのも有効です。ただし**答えを書かせるのではなく、原因を一緒に絞り込む**使い方をしてください。
