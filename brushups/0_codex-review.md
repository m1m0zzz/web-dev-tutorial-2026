## 1章へ持ち越し

**1.8 に、参照用リポジトリを remote として足す手順を書く。** 0章はその役割を説明するだけにとどめた。実際のコマンドは、リポジトリを clone した直後に置くのが自然なため。

```bash
git remote add -t 'chapter-*' -t main tutorial https://github.com/m1m0zzz/web-dev-tutorial-2026.git
git fetch tutorial
```

`-t` を付けているのは、Renovate の作業ブランチまで取ってこないようにするため。空のリポジトリでも、履歴が無関係でも動くことは確認済み。remote 名を `upstream` にしないのは、fork ではないため。

## 2章で決着（#3）

**「任意) の節を飛ばすと、5章の CI が落ちる」件は、2章のブラッシュアップで決着しました。** 2.10（oxlint / oxfmt）から「任意)」を外し、必須の節にしています。5.2 のワークフローが `npm run lint` と `npm run format:check` を無条件で実行する以上、その2つを作る節が任意なのは筋が通らないためです。

これに伴い、0章の「任意) の節は読み飛ばして構いません」という記述を元に戻しました。
