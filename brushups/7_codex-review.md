# 7章 codex レビュー（2026-08-23）

[`docs/07_features.md`](../docs/07_features.md) のレビュー結果です。15件すべてに対応しました。**うち3件はコードの不具合で、`apps/web` を修正しています**（7章のコミット）。

## コードの修正を伴うもの

### #6 公開状態を変えても、公開一覧が更新されない

`useUpdatePost` が無効化していたのは `['posts']` だけでした。公開一覧は `['public-posts']`、ユーザーページは `['user-posts', userId]` を使っているため、**非公開に戻したメモが `/public` に残って見える**状態でした。

`usePosts.ts` に `publicPostsKey` / `userPostsKey` を定義し、作成・更新・削除の `onSuccess` で3つとも無効化するようにしました。`['user-posts']` は前方一致で、どのユーザーのぶんも対象になります。

### #9 所有者にも、一瞬だけ閲覧専用の画面が見える

`PostDetailPage` がメモの取得だけを待ち、**セッションの確認を待たずに所有者を判定していました。** `useSession()` の `data` は取得中も `undefined` なので、メモの取得が先に終わると「他人のメモ」として扱われます。`isPending` を受け取って待つようにしました。

**同じ節で「`isPending` の分岐を飛ばすな」と書いておきながら、隣のページで飛ばしていた**形です。

### #7 公開の確認ダイアログが、限定公開だと誤解させる

「URL を知っている人が読めるようになります」と出していましたが、実際には [7.3](../docs/07_features.md#73-公開一覧ページ-public) で `/public` に一覧されます。**「公開メモの一覧に載り、ログインしていない人でも読めるようになります」**に変更しました（コードと記事の両方）。
