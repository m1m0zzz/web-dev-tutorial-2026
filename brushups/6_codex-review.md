# 6章 codex レビュー（2026-08-23）

[`docs/06_api-integration.md`](../docs/06_api-integration.md) のレビュー結果です。18件の指摘を **対応済み16件 / 記事で限界を明示2件**に分類しました。**この章がいちばん穴が大きく、記事どおりに進めても動かない状態でした。**

## 特に大きかったもの

### #1 6.3 の手順では、そもそもデータが取れない

`GET /posts` は [3.10](../docs/03_backend.md#310-better-auth-を導入しposts-をユーザーに紐づける) で認証必須にしています。しかし 6.3 の `fetch` はトークンを送らず、トークンを送れるようになるのは 6.6 です。**記事どおりに書くと 401 が返り、「リロードしてもデータが消えず表示される」という完了条件に到達できません。**

**認証の要らない `GET /public/posts` で `fetch` の形を確認する**構成に変えました。自分のメモを扱うのは 6.6 以降であることも明記しています。

### #3 / #4 React Query と認証画面のコードが1行も無い

「`useQuery` によるデータ取得」「サインアップ画面」「ログイン画面」が**扱うことの箇条書きだけ**で、実装がありませんでした。`hooks/usePosts.ts`、`main.tsx` の `QueryClientProvider`、`LoginPage.tsx` を掲載し、`SignUpPage` と各ページの変更点を書きました。
